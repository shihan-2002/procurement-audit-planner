What the harness runs

Live run

Every judgment is made by Claude () through the API: the skill reads the rulebook, the analysts write and run Python, the risk-assessor rates, the team plans, challenges and checks. Expect 30 to 60 minutes and a few dollars; the server caps each run's spend.

Replay run no API key needed

Replays the model judgments of a recorded live run (rules, history, first ratings, the plan, the challenges). Everything else runs for real on a fresh workspace: the spend-analyst's scripts, every verifier, the register and pack builders, all four QA checks. Your gate decisions change the result.
